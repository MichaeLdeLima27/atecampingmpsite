HTML

Sobre pré-processadores HTML

Os pré-processadores de HTML podem tornar a escrita em HTML mais poderosa e conveniente. Por exemplo, o Markdown foi projetado para ser mais fácil de escrever e ler em documentos de texto, e você pode escrever um loop em Pug.

Saiba mais · Versões

Adicionando Classes

No CodePen, tudo o que você escreve no editor HTML é o que vai dentro das <body>tags de um modelo HTML5 básico . Portanto, você não tem acesso a elementos superiores, como a <html>tag. Se quiser adicionar classes que possam afetar todo o documento, este é o lugar para fazer isso.

Sobre o <head>

No CodePen, tudo o que você escreve no editor HTML é o que vai dentro das <body>tags de um modelo HTML5 básico . Se precisar de algo no <head>documento, insira o código aqui.

CSS

Sobre pré-processadores CSS

Os pré-processadores CSS facilitam a criação de CSS. Todos eles oferecem recursos como variáveis e mixins para fornecer abstrações convenientes.

Saiba mais · Versões

Precisa de um complemento?

Base CSS

Sobre o CSS Base

É uma prática comum aplicar CSS a uma página que estiliza os elementos de forma que sejam consistentes em todos os navegadores. Oferecemos duas das opções mais populares: normalize.css e reset . Ou escolha "Nenhum" e nada será aplicado.

Prefixo do fornecedor

Sobre prefixo de fornecedor

Para obter o melhor suporte entre navegadores, é uma prática comum aplicar prefixos de fornecedores às propriedades e valores CSS que exigem seu funcionamento. Por exemplo, -webkit-ou -moz-.

Oferecemos duas opções populares: Autoprefixer (que processa seu CSS no lado do servidor) e -prefix-free (que aplica prefixos por meio de um script, no lado do cliente).
